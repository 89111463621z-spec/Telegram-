# ГАБ Сборщик: бот-«почтальон» для Google Таблицы

Бот складывает каждое пересланное в рабочую группу сообщение на лист **«Входящие»**.
По команде «актуализируй» Claude разбирает новые строки и переносит их на лист **«МСК_Парсим»** рабочей таблицы.

## Установка (один раз, ~10 минут, лучше с компьютера)

1. Google-таблица → **Расширения → Apps Script**.
2. Удалить всё в `Code.gs`, вставить код из [`Code.gs`](Code.gs), нажать 💾.
3. **Настройки проекта** (⚙️ слева) → **Свойства скрипта** → добавить:
   - `BOT_TOKEN`: токен от @BotFather
4. **Развернуть → Новое развёртывание** → тип **Веб-приложение**:
   - Выполнять как: **Я**
   - Доступ: **Все**
   - Нажать «Развернуть», разрешить доступ, скопировать **URL веб-приложения**.
5. В **Свойства скрипта** добавить `WEB_APP_URL` со скопированным URL.
6. В редакторе выбрать функцию и нажать **Run** (результат в Execution log):
   - `setup`: готовит лист «Входящие»
   - `setWebhook`: должен прийти ответ `"ok":true`
   - `checkWebhook` / `testWrite`: диагностика
7. Только теперь добавить бота в группу менеджеров.

## Что сохраняется
- Все **пересланные** сообщения.
- Свои сообщения в группе длиннее 120 символов (вставленный текст объявления).
- Короткие реплики («глянь», «ок») игнорируются.

## Ограничения
- Если у автора скрыта пересылка, его @username не придёт. Тогда контакт ищется в тексте.
- Бот не видит сообщения, отправленные до его добавления в группу.
- При изменении кода нужно сделать **Развернуть → Управление развёртываниями → ✏️ → Новая версия**.
