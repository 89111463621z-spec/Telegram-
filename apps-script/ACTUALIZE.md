# Команда «актуализируй»: как Claude переносит объекты

1. Прочитать лист **«Входящие»** таблицы «ГАБ входящие» (`18YCy0pkS-3mSarf9XVHmg8wcuLdW7e7JO-P0X_Z0y9Q`), строки со статусом `новое`.
2. Сгруппировать строки по колонке **«Объект»** (одна группа = один объект: альбом или серия постов одного автора в пределах 2 минут).
3. Текст берётся из колонки «Текст»; если цифры на картинке — открыть фото из папки «Копия для разбора»
   (Google Диск → «ГАБ медиа (копия для разбора)», доступ на чтение выдан подключённому аккаунту).
4. Записать объект в **«Отдел Продаж сводная шахматка» → лист МСК_Парсим** (`1k-DlvBGrGusQJu7yLpRGWLBZzUsJjiMJraL9HwRsZpo`).
   Только этот лист, только колонки A–I, новые колонки не добавлять:
   - A Дата публикации — дата исходного поста
   - B Контакт / Ник — @username автора (+ название в скобках)
   - C Цена — числом (формат столбца: `26 640 000 ₽`)
   - D Арендатор/ы
   - E МАП — числом (формат столбца: `254 500 ₽`)
   - F Окупаемость — текстом, как в объявлении: «8 лет», «7 лет 6 мес», «18 мес». Если в объявлении нет —
     посчитать Цена ÷ (МАП × 12) и записать так же текстом с пометкой «(расчёт)».
     Расхождение заявленной и расчётной окупаемости — в комментарий.
   - G Адрес — `=HYPERLINK` на Яндекс Карты
   - H Комментарии — площадь, условия, потенциальный МАП, ссылка на папку в Битриксе, пометка о видео > 20 МБ
   - I Комиссия агентству, % — только если указана
5. Отсортировать по цене. Отметить строки «Входящих» как `обработано` (нужен доступ «Редактор»).
